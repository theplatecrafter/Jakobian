# Development 0.10.0 — P04a enforced load/start admission

The [fixed P04a checkpoint](../planning/prompt-roadmap.md) splits proposed P04 before coding: enforce five load/start boundaries first, then let P04b address live publication, unpack/transfer/spherical consumers and hole flight. This increment does not publish a live torus or certify active-flight safety.

## Implementation

A bounded core policy keeps legacy permission distinct from compatibility/adoption. Version-checked Harmony prefixes inspect raw, proto and live world state before guarded native construction, ID clearing and start/flight work. Changed/future/malformed/unsupported data and unknown native references are refused. Expected hook integrity and foreign ownership are audited without deleting another owner's patches. Required installation failure refuses startup.

Community HarmonyKSP files/notices are hash-locked; deployment refuses conflicting/duplicate libraries. See [policy, boundaries, provenance and bypass limits](../modders/load-admission.md).

## Evidence and reflection

The final Release build passed **509,293 core assertions** with zero warnings/errors. The graphics-enabled native admission fixture passed **23 refusal cases across five guarded routes**. Each refusal recorded zero constructor, ID-clear, FlightState.Load and scene calls, with unchanged current game/vessel/scene/save folder. Allowed-load positive controls exercised the constructor and ID-clear observers. Separate isolated positive controls for the other two observers remain absent.

On the same deployed files, Atlas landed on its terrain collider, adopted five radial world descriptors, saved and restored them through native reload. All six historical 0.2.0/0.3.0 landed saves preserved pose through reload; the excluded stock Kerbin orbit coasted ten seconds and reloaded successfully. All three final native logs contain zero `Exception` tokens. Preliminary runs are superseded by the final log/snapshot receipts in [exact evidence](v0.10.0-validation.json).

All 17 installed files match the three final deployment snapshots and build outputs. Eighteen preexisting persistent files, six original/staged historical inputs (12 paths), four template assemblies and eight prior fixture assets retain their hashes. Seven new private regression output folders were archived under baseline `.dev/regression-results` after the game exited. The dependency conflict fixture refused a different existing library without replacing it or writing any new dependency files. The seven installed community files/license notices and source archive match the lock.

For human testing, Resume Saved → `JakobianProbe-JakobianAtlas-20261027-042133` uses this final build. The five playable radial moons and detached torus preview remain available. See [human guidance](human-testing.md).

Reflection: the bounded load/start goal has executable native evidence, including mutable proto/live records and hook ownership. Review found identity-masking, stored/live precedence and failed-loader bootstrap edges; these were repaired before final verification. This is a useful prerequisite for live general bodies, but it does not implement their terrain, vessel unpack/transfer, hole flight or rotating physics. The refusal popup/save-browser interaction and per-frame patch-audit cost remain unmeasured. Foreign postfixes and hostile same-frame unpatch/calls are outside the supported cooperative profile. The [independent assessment](p04a-review.md) awarded **96/100**, all criteria met, with four points deducted for verification breadth. P04a is complete and awaits the owner's continue/redo decision; P04b is next.
