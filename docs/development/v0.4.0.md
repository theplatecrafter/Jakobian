# Development 0.4.0 — closed-solid queries, torus collider foundation and upgrade regressions

This slice advances the nonradial backend and adds actual historical-save/stock-orbit checks. The active human test pack retains the same four radial moons. A native torus celestial body is still gated on general-body lifecycle, spherical-consumer adapters, streaming and anchors.

Implemented:

- A closed-solid core query contract with explicit occupancy, signed distance, sorted entry/exit/touch contacts, no-hit results and budget/precision failure statuses. Sphere and torus providers use bounded polynomial root isolation.
- Deterministic anchored torus mesh patches, matching periodic seams and outward winding on inner and outer surfaces.
- An isolated native mesh-collider experiment checking inner/outer/top contacts and an empty hole under a rotated transform.
- A regression runner that stages immutable copies of all six retained 0.2.0/0.3.0 landed fixtures, loads each into a private Sandbox, checks pose/navigation, saves/reloads and preserves original input files.
- A stock Kerbin circular-orbit coast/reload fixture with Jakobian query/camera exclusion checks.

The [solid/mesh architecture](../architecture/solid-queries-and-torus-mesh.md) defines numerical semantics and remaining integration gates. Builds have zero warnings/errors; pure-core checks pass **112,034 assertions**. Exact tested hashes, cases, input hashes and scope are in [v0.4.0-validation.json](v0.4.0-validation.json).

## Native results

The exact deployed build passed both complete suites:

- KSP Mono executed the new solid query: four diameter crossings, no axial hole crossings, centre classified as empty.
- Native cooking/raycasting passed on 32 rotated torus collider patches, including inner/outer/top walls and an empty hole.
- All six retained 0.2.0/0.3.0 landed Sandbox fixtures loaded with preserved pose, passed navigation checks, and were saved/reloaded in private copies. Original and staged input hashes remained unchanged.
- A stock Kerbin circular orbit coasted for ten seconds, remained outside Jakobian query/camera ownership and reloaded within the declared orbit tolerance.
- All three radial nonspherical fixtures again passed fresh navigation, actual ASL/AGL altimeter, camera, terrain contact, landing and save/reload checks.

Both final logs contain **zero exception tokens**, including process exit. The first upgrade runner loaded/reloaded all six historical poses and passed the stock orbit check, but starting worlds directly during the previous fixture's scene teardown produced native UI callback exceptions. The runner now returns through MainMenu between worlds and yields before reload. Successful flight/regression probes also return to MainMenu before quitting, avoiding the old direct-flight shutdown ordering. No global native UI patch was installed; arbitrary/forced shutdown and all interactive transitions are not thereby certified.

Only this turn's 28 private upgrade/stock result folders were moved under baseline's `.dev/regression-results`. Preexisting save folders were left in place. Three fresh 0.4.0 landing saves are listed in the evidence record for human testing.

This does not freeze descriptors in saves, implement arbitrary config migrations, certify every stock scene/craft/mod, add a landable torus fixture or complete M1/M2 acceptance. Existing visual seams, static landed persistence and Kopernicus coexistence limitations remain open. Next implement general-body construction/streaming and hole-aware native consumers, then surface-anchor persistence and the actual torus vessel fixture.
