# Development 0.2.0 — standalone loader and first shape backend

## Implemented

- Independent ConfigNode parsing and one-time native prefab publication at KSP's PSystemSpawn boundary; no Kopernicus assembly dependency.
- Stock hierarchy retained, with four appended fixture bodies and stable native indices 17–20.
- Restricted radial backend: sphere, ellipsoid, superellipsoid/rounded cube and peanut; native PQS heights, terrain colors and collider generation.
- Corresponding scaled-space meshes, native point gravity and ordinary native uniform rotation.
- Independent mutable terrain/scaled materials per new body, preserving stock template assets during fade updates.
- Explicit static-body frame initialization for experiments; static landed persistence is not certified.
- Source/prefab versus spawned-body checks, rejected unsupported config values/nodes, native startup and flight probe tools.
- Automatic successful Release deployment into baseline, build hashes, private probe saves and a human launcher/guide.

This is an initial implementation slice. It does not yet supply a general-topology mesher/collision streamer, torus hole or hollow body, arbitrary mesh import, spatial air/water, noncentral numerical flight, frozen saved-world descriptors or full spherical/Kopernicus parity. Native rotation of a radial body is distinct from the future rotating-habitat frame backend.

## Verification and investigation

Core tests pass **38,021 assertions**, including 2,000 independent implicit-surface checks for ellipsoid/superellipsoid and radial bounds/symmetry/direction invariance. Release builds have zero warnings/errors. Native startup has published/bound all four bodies with Kopernicus absent and matched their PQS heights against analytic queries; stock Kerbin's identity/radius is checked. Native tests also check surface-frame validity and live terrain ownership.

Early native experiments are retained rather than presented as passes:

| Experiment | Finding / disposition |
| --- | --- |
| initial index 16 | stock has 17 bodies; validation rejected the conflict before publication; fixtures now use 17–20 |
| terrain modifier on PQS root | native height query ignored that registration; moving it to a direct child enabled all shape queries |
| nonrotating template clone | native BodyFrame matrix was uninitialized; initializing only the quaternion was insufficient; explicit static frame publication added |
| headless flight | startup shape/frame checks passed, but native RenderTexture creation crashed on flight entry; flight harness now requires graphics |
| static ellipsoid drop | actual terrain collider and native LANDED flag observed; zero-angular-momentum stock conics became degenerate and landed reload did not pass |
| human fixture revision | fixtures use ordinary six-hour rotation; drop keeps a small tangential component; static anchored persistence remains an explicit open task |
| terrain lifecycle | separate fade settings, rebuild-on-target change and explicit post-spawn terrain/body rebinding added; native flight/reload diagnostics record the result |
| unpowered cube drop | capsule exploded on impact; final probe uses explicit test-only 3 m/s braking, with native collider contact and landed-state detection unchanged |
| sequential cube view | collider/landing/reload passed while the initial camera view lacked terrain; re-aiming after touchdown restores a ground view; material isolation separately prevents cross-body fade writes |

The final graphics suite passed native terrain contact, LANDED state and landed save/reload on **all three nonspherical fixtures**. All four bodies passed startup shape/frame/material-ownership checks. Exact deployed hashes, log identity, saves and per-body results are in [v0.2.0-validation.json](v0.2.0-validation.json). Descent uses test-only velocity braking; it does not assign contact or landed state. A private stock-pod probe is not exhaustive craft/EVA/scene/mod coverage.

Visual inspection confirms terrain in the re-aimed landed views, but template-derived terrain materials still show color/lighting discontinuities between some quads. Camera motion/collision and terrain material quality need further manual acceptance; renderer counts alone do not prove a correct image.

The final log contains no exception tokens before `FLIGHT_SUITE_PASS`, then reports a native `KnowledgeBase.OnMapFocusChange` null reference during process shutdown (`MapView.OnDestroy`). This is retained as an unresolved shutdown/UI lifecycle issue; a passing flight suite is not an exception-free full-game acceptance result.

## Human testing and next work

Use [human testing](human-testing.md). Preserve fixture identities/dimensions/spin after this build's handoff so user test saves remain addressable. Original failed pre-handoff probe saves are experimental evidence, not migration fixtures for a released product.

Close remaining native render/contact/reload and stock regression gaps, then implement canonical general-surface queries, streamed torus contacts and stable surface-anchor persistence. That path advances the complete standalone framework rather than treating the radial backend as a universal topology solution.
